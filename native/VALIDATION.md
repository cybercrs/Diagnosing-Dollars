# Native browser validation

Passed: **20** existing unit/AppTest tests, **10** native test groups, and **12** actual Chromium browser groups. Native parity covers 84 independently generated Python scoring cases, ratio calculations/tolerance boundaries, exact Python currency/decimal rounding, evidence penalties, reflection criteria, saved token compatibility, malformed/future state rejection, reset and engine-level review guards.

The final complete local walkthrough exercised a mixed **37/39 (95%)** case, a perfect **39/39** case, and an all-wrong **0/39** case. It checked all four debrief labels, original required inputs and submission-only gates, repeated/review behavior, every prior page, account/liquidity order preservation, old/native snapshots, partial/formatted numeric drafts, rationale refresh behavior, submitted rubric flags, reset, independent contexts, Enter/focus, 44px targets, CSV content, keyboard dialog expansion and 1280/900/390px layouts. A separate focused browser check also verified raw rationale text survives Back/Forward within the same tab, never changes the saved URL, and clears on refresh. The reviewed CSV uses LF line endings for repository readability; the actual download uses standard CRLF and its complete contents were checked. There were zero page errors, console errors, external requests, runtime/package downloads or Python-server requests in the final run.

An earlier browser pass exposed a textarea renderer name shadowing error at diagnosis. That UI-only collision was corrected, then the full browser suite above passed. The original failed result is retained as `pre-textarea-fix.json`; no unresolved failure remains. Original lesson/scoring modules were never modified.

The final seven native assets total **109,714 uncompressed bytes**, measured from the built HTML/CSS/JavaScript files, excluding manifest/provenance metadata. Five cache-disabled fresh Chromium contexts on local loopback measured **1804.0 ms median**, range 1164.3–2478.0 ms, navigation to native-ready after initial saved-link encoding. The saved cloud environment was used for development and other local build activity; these are not hosted-network, school-device, network-speed or classroom-capacity measurements.

The title, metadata, native downloads and all 21 captured variants plus dynamic performance labels were checked for provisional branding. Syntax, Python compilation, export reproducibility and whitespace checks passed. No configured linter is supplied; Ruff is unavailable, so no Ruff result is claimed.

`source-protection.json` verifies every existing source file except allowed `.gitignore` additions byte-for-byte. Source is isolated on `native/html-js`; publication adds only `/js/` on `stlite-browser` while preserving all existing static blobs. Main, original Python/Streamlit code, dependencies, server files and Pages settings remain unchanged. Exact commits and successful CI/Pages run are reported separately after publishing. Hosted browser testing was not run because the known proxy denial is respected.
